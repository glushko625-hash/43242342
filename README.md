# Aurora Notes

Современное настольное приложение заметок с интеграцией ИИ. Aurora Notes позволяет вести локальные заметки и изменять выделенный текст, учитывая контекст всей заметки, с помощью модели Gemini.

## Возможности

- локальное хранение заметок с мгновенным автосохранением;
- удобное управление заметками (создание, переименование, экспорт в Markdown);
- современный тёмный интерфейс с трёхпанельной компоновкой (заметки, редактор и чат);
- интеграция с Google Gemini: редактирование выделения на основе подсказки пользователя с учётом всей заметки;
- встроенный чат с ИИ, который учитывает историю беседы и содержимое заметки;
- переключение между моделями (Gemini 2.5 Pro и Gemma 3 27B IT) прямо в панели чата — выбор влияет и на чат, и на редактор;
- настройки внутри приложения для сохранения ключа API;
- обработка ошибок и подсказки, если ключ API не настроен или ответ пустой.

## Запуск приложения

1. Создайте и активируйте виртуальное окружение (опционально):
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   python -m app.main
   ```

4. Откройте «Настройки» в верхней панели редактора и сохраните ваш ключ Gemini (его можно получить в консоли Google AI).
   Ключ шифруется не требуется — он хранится локально в файле `settings.json` в каталоге `.aurora_notes`.
   Если переменная окружения `GEMINI_API_KEY` уже задана, приложение подхватит её автоматически.

5. Выберите подходящую модель в выпадающем списке чата — выбранная модель применяется ко всем запросам (чат и изменение выделения).

При первом запуске в домашней директории создаётся папка `.aurora_notes`, где хранятся ваши заметки.

## Экспорт в исполняемый файл (EXE)

Используйте PyInstaller:

```bash
pip install pyinstaller
pyinstaller --name "AuroraNotes" --noconfirm --windowed --add-data "app/*.py;app" app/main.py
```

Полученный файл `AuroraNotes.exe` появится в каталоге `dist`. При первом запуске EXE убедитесь, что переменная `GEMINI_API_KEY` доступна в системе.

## Структура проекта

```
app/
├── ai.py             # Обёртка над google-genai
├── main.py           # Qt-интерфейс, чат и логика приложения
├── note_store.py     # Работа с локальными заметками
└── settings_store.py # Сохранение настроек и ключа API
requirements.txt
```

## Решение неполадок

- **Нет доступа к ИИ:** проверьте, что установили пакет `google-genai` и указали ключ в настройках (или переменную `GEMINI_API_KEY`).
- **PyInstaller не создаёт exe:** убедитесь, что используете Python 3.10+ и запускаете команду в активированном окружении.
- **UI не отображается на Windows:** установите последнюю версию драйверов видеокарты и обновите Qt (PySide6).
