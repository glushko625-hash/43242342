# Contextual Notes Desktop App

Electron-приложение для ведения заметок с интеграцией ИИ. Позволяет создавать несколько заметок, редактировать их и запускать контекстное изменение выделенного текста с учётом содержимого всей заметки.

## Возможности

- Список заметок с быстрым переключением и предпросмотром Markdown.
- Автосохранение в локальное хранилище.
- Панель ИИ: введите инструкцию, выделите фрагмент и получите предложение.
- Поддержка OpenAI (при наличии ключа) с офлайн-фолбэком.

## Запуск

```bash
cd electron-app
npm install
npm start
```

## Настройка ИИ

1. Зарегистрируйте ключ в переменной окружения **OPENAI_API_KEY** перед запуском приложения:

   ```bash
   export OPENAI_API_KEY="sk-..."
   npm start
   ```

2. Если ключ не указан или запрос завершается ошибкой, приложение вернётся к встроенным офлайн-преобразованиям (краткое резюме, простые перефразирования и т. п.).

## Использование

1. Создайте новую заметку или выберите существующую.
2. Введите/отредактируйте текст — предпросмотр Markdown обновляется автоматически.
3. Выделите фрагмент текста, задайте инструкцию для ИИ (например, «перефразируй» или «кратко подытожь») и нажмите «Изменить выделенный текст».
4. Просмотрите предложение ИИ и при необходимости примените его к заметке.
